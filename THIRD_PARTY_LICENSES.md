## mpvX upstream relationship

mpvX is a fork/derivative of **mpvRex**. mpvRex itself describes its roots as coming from **mpvEx**, which in turn builds on **mpv-android**. The upstream projects remain credited separately, and their applicable license terms continue to apply to any code or assets derived from them.

## Important

- Third-party code must remain under its applicable original license. The mpvX Apache-2.0 license does not relicense third-party code.
- Copyright notices and required attribution from third-party source files must be preserved when applicable.
- If code or assets are copied or adapted from a third-party project, its license requirements apply to that copied or adapted material.
- Merely listing a project here does not grant permission to copy code or assets beyond the permissions provided by that project's license.
- The repository should be reviewed against the actual source and dependency tree before distributing a release, because transitive dependencies can have additional licenses and notices.
